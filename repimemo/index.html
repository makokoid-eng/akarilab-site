接客の記憶を、
次の接客の力に

接客のメモを残しておくと、お客さまの文体を少しずつ学習して、
次に送るメッセージの下書きまで作ります。
指名客の電話番号も、同じ LINE の中にまとめて置けます。

できること

メモを残す

退勤後にまとめて入力しても、出勤前にひとつずつ思い出しながら入れても大丈夫。短いメモでも残しておくと、後から自分が助かります。

文体の学習

過去のやり取りから、自分の語尾や言い回しを少しずつ覚えていきます。次のメッセージの下書きが、自分の言葉に近い形で出てきます。

メッセージ下書き

お客さまの状況とメモを見て、送る前のたたき台を作ります。そのまま送らず、自分で直してから送る前提の下書きです。

NG情報のメモ

「この人にはこれは出さない」を自分用に残しておけます。共有範囲が必要なときの仕組みは別ページで案内しています。

予約の整理

媒体の予約情報をテキストで貼ると、該当する人の過去メモと並べて見られます。

電話の検索

知らない番号からの着信を、登録した連絡先の中から探せます。指名のお客さまの番号を取り違えにくくなります。

使う場面

出勤前に、今日来る予定の人を確認する

予約と過去のメモを並べて見られるので、移動中の数分でだいたいのことを思い出せます。

退勤後に、その日の接客をまとめて入れる

細切れに打たなくていいので、家に帰ってから一度に書き出して、寝る前に閉じられます。

指名客から電話が鳴ったとき

登録番号の検索で、誰からの着信か出ます。出る前に、過去のメモを開ける時間ができます。

同じ媒体の中で、何度も来る人を覚えておきたいとき

過去のメモを並べて見ると、相手の好きな話題や避けたい話題が、自分の言葉で残っています。

よくある質問

店舗導入の流れは？
店舗向けの利用方法は 別ページ にまとめています。導入の相談は LINE で受け付けています。
個人で使えますか？
個人での利用を想定して作っています。LINE 友だち追加だけで使い始められます。店舗に所属していなくても問題ありません。
予約システムと連携しますか？
シティヘブン形式の予約情報をテキストで貼ると、該当キャストに通知が飛ぶ仕組みを試験的に動かしています。直接の API 連携は今のところありません。
データの取り扱いは？
メモと連絡先は、登録したアカウントの中だけに置かれます。第三者に渡したり、広告に使ったりはしません。退会時はデータを削除できます。
料金は？
個人利用は無料で使えます。店舗向け機能の料金は準備中です。
途中でやめられますか？
LINE のブロックでいつでも止められます。残ったメモは自分で削除できます。
