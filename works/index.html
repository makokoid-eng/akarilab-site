制作実績・デモ

業種・目的に合わせて作る、受託 Web 制作のサンプル集

AkariLab では、LINE Bot の開発と並行して、企業サイト・店舗サイト・イベント告知ページなどの受託 Web 制作も手がけています。
ここでは、業種や目的に合わせて作ったデザイン・構造のデモをジャンル別に公開しています（掲載している会社名・店名・住所・数値・日付はすべて架空です）。

01飲食

  • とんかつ ひなた亭

    宮崎・日向のとんかつ店を想定した飲食店サイトのデザインデモ。メニュー・店舗情報・お店のこだわりを一枚で見せる構成です。

    デモを開く（別タブ）→

  • 純喫茶つた（WordPress）

    山あいの喫茶店を想定した、WordPress で制作した飲食店サイトのデザインデモ。お品書き・店舗情報・お知らせを、落ち着いた誌面のトーンでまとめた構成です。

    デモを開く（別タブ）→

02不動産

  • 海風不動産

    沖縄の土地・住まいを扱う不動産会社を想定したサイトのデザインデモ。物件種別・エリア・相談への導線を整理した構成です。

    デモを開く（別タブ）→

03製造

  • 丸誠精工（金属加工・精密部品製造）

    小ロット試作から量産までを担う金属加工メーカーを想定した BtoB コーポレートサイトのデザインデモ。事業内容・選ばれる理由・設備実績・採用情報・会社概要までを一枚で見せる構成です。

    デモを開く（別タブ）→

04イベントLP

  • DOG DAYS PARK 2026

    犬と楽しむ秋の公園イベントの告知 LP のデザインラフ。開催概要・見どころ・アクセスを一枚にまとめた、告知に特化した構成です。

    デモを開く（別タブ）→

05医療

  • あかり内科クリニック

    地域のかかりつけ医を想定したクリニックサイトのデザインデモ。診療案内・医師紹介・診療時間・アクセスに加えて、診療内容 → 日付 → 時間 → 確認と進む Web 予約フローまで作り込んだ構成です。

    デモを開く（別タブ）→
