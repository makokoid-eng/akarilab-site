3時11分、コードを書く前にやっていたこと

2026-05-13 · note 原文

連載「触り始めて9ヶ月の記録」第2話

2024年12月12日、午前3時11分。

布団に入る前に、3行だけ日記に書いた。

夢中になるって大事 これって没頭 すごいな。

それだけで止まらず、もう4行続いていた。

あっという間。 ココナラのサービスも作ってティックトックのアカウント作って投稿できた！ 凄くすごく楽しかった。 もっとより深くAI使いこなしたいな

合計7行。前日の12月11日の夜23時40分にも、こう書いていた。

今日はAIの要求通りに生活したー。 筋トレメニューなどは易しくはないけど、自分自身の成長が目に見えるから楽しい。

「AIの要求通りに生活する」というのは、当時の自分のなかでDラボの講座とDaiGoのAIチャンネルから学んだことを、ChatGPTに「今日のスケジュール組んで」「今日のメニュー考えて」と聞いて、その通りに動く、ということだった。

筋トレ、瞑想、食事、仕事、休憩、就寝時間。

それを毎日、AIに組み立てさせて、その通りに過ごしてみる。少し馬鹿げているようにも見える生活を、当時の自分は楽しんでいた。

そして、12月12日の3時11分。

ココナラに自分の商品ページを作り、TikTokにアカウントを作り、初投稿まで一気に終えていた。

「ココナラの何を売ったのか」「TikTokに何を投稿したのか」は、いま正直に言うと、はっきり覚えていない。当時、副業に関わっていた商材に絡んだものだったとは思う。商品ページのデザインに何時間かかけた記憶はある。TikTokは10秒のスライドショーみたいなものを投げた記憶がある。

中身よりも、その夜の手応えが7行に集約されていた。

「夢中になるって大事 これって没頭」

44歳の人間が、午前3時に、自分の生活の中で、ココナラとTikTokという2つの新しい場所に「何かを置いた」体験を、初めてした夜だった。

ここで気づいてほしいのは、この夜、まだ一行もコードを書いていない、ということだった。

Git も知らなかった。Node.js もインストールしていなかった。LINE Bot という言葉も聞いたことがなかった。プログラマー的な意味での「個人開発者」とは、まだ呼べる状態じゃなかった。

それでも、人生で初めて、自分のなかから「何か」を取り出して、世に出すという行為を、一気に2つ、夜中の3時にやっていた。

<!-- ここから先は有料 -->

「出す」を初めてやった日

いまから振り返ると、この夜が、僕の個人開発の本当のスタートラインだった。

8月29日の台風の夜（第1話）にDaiGo AIチャンネルで「生成AI」という言葉を知ってから、103日後。

その103日のあいだに、僕は ChatGPT を業務で使い始め、Excelの関数を組ませ、面談記録の要約を作り、画像生成AIに興味を持ち、Dラボでバリューランタンというワークをやって、自分の中心に「子ども」という存在がいることに気づき、副業を始めたばかりの恋人とは別れていた。

11月26日にはこう書いている。

副業したいなという感情が発生した。そうすることで自分のスキルを更に磨くことができると思って。 いろいろ触って動画作って接客の動画マニュアル作りたい。飲食に関わらずステップアップのチャンスが生まれる気がする。

そして16日後、12月12日の3時11分に、ココナラとTikTokを公開していた。

「投稿する」と「コードを書く」は、まったく違うように見えて、実は同じ筋肉を使う、と思う。

両方とも「自分の頭の中にあったものを、世の中の誰かが見られる場所に出す」という行為だ。

ココナラの商品ページに、自分の言葉で説明を書いて、価格を決めて、サムネイル画像を貼って、「公開」ボタンを押す。

これは、後にコードを書いて GitHub に push（=コードを保管庫に上げる操作）するのと、構造的にはほぼ同じだ。

「内部の何かを、外に置く」という、ただ一点の動作。

44歳の自分は、その夜、その動作を初めて自分の意思でやった。

それまでにやっていなかったこと

飲食の現場で店舗運営を20年、ずっと続けてきていた。

毎日、シフトを作って、売上を確認して、原価を計算して、面談の議事録を書いて、報告書を提出していた。

その意味で「アウトプットをずっと出していた」とも言える。

でも、それは全部「会社の中」のアウトプットだった。提出先は決まっていて、見る人は決まっていて、評価軸も決まっていた。

20年のあいだ、自分の名前で、自分が決めた値段で、不特定多数の知らない人に向けて、自分の中の何かを「出した」ことは、一度もなかった。

それを、ココナラとTikTokという2つの場所で、夜中の3時に、立て続けに2回やった。

「凄くすごく楽しかった」と書いてあるのは、たぶんこの感覚への驚きだったと思う。

仕事を21年やってきても味わったことのない種類の手応えが、そこにあった。

ここから10ヶ月

ここからGitに最初のコミットをするまで、ちょうど10ヶ月半かかる。

12月のこの夜から、ライブ配信を始めるまで5週間。 初マラソンを走るまで7週間。 「AIを使って新業態開発を探ろう」と決意するまで2ヶ月。 日記アプリの記録が3月の自己内省を最後に止まるまで3ヶ月（記録自体は止まったわけではなく、ChatGPTとの対話に形を変えて続いていく）。 Git、Node.js、VSCodeのインストーラーをダウンロードするまで5ヶ月。 LINE Bot が初めて echo（=送ったものをそのまま返すだけの最小機能）を返すまで8ヶ月半。 食改善Bot（Google Apps Scriptで作った最初のプロダクト）の prod 完成まで10ヶ月。 そして、repimemo というLINE Botのコードを GitHub に push して、Cloud Run（=Googleのサーバー実行サービス）への自動デプロイ（=自動で本番環境に上げる仕組み）が動き出すまで10ヶ月半。

10ヶ月半のあいだ、12月12日に体験した「夜中の3時に何かを出す」という感覚は、ずっと自分の中に残り続けていた。

あの夜のココナラの商品は半年で公開停止、TikTokのアカウントも3本投稿で止まった。商業的にはほとんど成果は出ていない。

ただ、ココナラはその後、1年半経って、別の形で動き始めた。コードを書けるようになった2026年5月、業務改善LINE Botの30分相談という新しい商品を出した。あの夜の「出す」体験が、ちゃんと続いていた。

「出す」という動作を一度自分の意思でやったことは、後にGitやCloud RunやLINE Messaging APIに触るときの、最大の助走になっていた、と思う。

技術を学ぶよりも、「出す」を最初に練習しておくほうが、たぶん効く。

もし、いまこれから始めるなら

ここからは、いまの自分が、当時の自分に伝えたいことを書く。

個人開発を始めたい人に、コードから入ることをすすめない。

最初にやるのは、もっと小さい「出す」だ。

note でも、X でも、ココナラでも、TikTok でも、Instagram でも、何でもいい。

自分の名前で、自分が決めた何かを、不特定多数の人に向けて公開ボタンを押す、という体験を、一度やっておく。

それは10円も生まないかもしれない。誰にも見られないかもしれない。それでも、「自分の中の何かを、世に置いた」という事実は、自分の中に残る。

この感覚があると、後でコードを書いて、Git だの GitHub だのよく分からない仕組みに何かを突っ込むときも、LINE Bot を Cloud Run に上げる仕組みがよく分からないまま動かすときも、「あ、これは前にやった『出す』と同じだ」と気づける。

少なくとも僕の場合、コードを書く10ヶ月半前の夜中の3時に、たまたまココナラとTikTokで先に「出す」を練習していたのは、いま思えば、相当ラッキーだった。

もし、これを読んでいるあなたが、まだ何も「出して」いないなら、今夜のうちに、何か一つだけ公開ボタンを押してみてほしい。

中身は何でもいい。

「出す」という動作を、自分の意思でやった、という事実だけが、後で効く。
