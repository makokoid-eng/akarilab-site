9ヶ月後の自分が、台風の夜の自分に書く手紙

連載「触り始めて9ヶ月の記録」最終話

2026年5月13日。

連載第1話で書いた「44歳、台風のホテルで『生成AI』を初めて聞いた夜」（2024年8月29日）から、ちょうど622日が経っていた。

いま、自分は45歳になっている。

そして、5つのプロダクトを並行で動かしている。

  • hidamari（子ども向けAI学習Bot）
  • moyalog（感情整理Bot）
  • repimemo（夜の店舗向け返信下書きBot）
  • VAC（本業の QSC 監査ツール）
  • okilockle（本業の勤怠記録ツール）

加えて、AkariLab note の毎日記事と、この連載「触り始めて9ヶ月の記録」と、それを拡散するための makochinta1-poster の自動投稿。

合計で、Cloud Run のサービスが5つ、GitHub のリポジトリが8つ。

毎日、それぞれを少しずつ整えながら、毎週日曜にこの連載を書いている。

622日前、台風のホテルで「生成AI」という言葉を初めて聞いた夜の自分には、まったく想像できない景色だった。

その自分に、いまの自分が手紙を書くなら、何を書くか。

最終話として、それを書こうと思う。

<!-- ここから先は有料 -->

まことくんへ

622日前のまことくんへ。

あの夜のことは、よく覚えている。

熊本のビジネスホテルで、台風で外に出られなくて、ノートパソコンを開いて、シフトを作りながら、Dラボの講座をBGMにしていた、あの夜。

DaiGo AIチャンネルに加入して、「生成AI」という言葉を初めて聞いて、日記に5行だけ書いて寝た夜。

当時関わっていた副業の商材の商品説明や興味を持ってもらえるツールとして動画やスライドなど作れたら面白い。 でもまだ今日やるべきことが出来ていないから少しでも進めなきゃな。

あの5行に、未来の自分の輪郭が、もう入っていた、と今は思う。

「動画やスライドが作れたら面白い」は、結局、AIで動画もスライドも作るようになった。

「今日やるべきことが出来ていない」は、結局、今でも続いている。45歳になっても、たぶん65歳になっても、自分は「やるべきこと」と「やりたいこと」のあいだで揺れているはず。

でも、622日後のいま、「やるべきこと」の中身が、まったく変わっている。

シフトを作ることでも、議事録を整えることでも、月末業務をこなすことでもない。

自分の作ったプロダクトを、もう少し誰かが使いやすい形に整えること。

それが、いまの自分にとっての「今日やるべきこと」になっている。

連載で書いた13のこと

622日のあいだに、自分は13個の節目を経験していた。

第1話、台風の夜にAIを知った。 第2話、午前3時にココナラとTikTokに何かを投げた。 第3話、AIに自分の話を聞いてもらった。 第4話、整えログに「アプリ進めなきゃ」と書いた。 第5話、転職と開発を同じスレッドで動かした。 第6話、LINE Bot が echo を返した。 第7話、食改善Botを作って、開発者の道具を揃えた。 第8話、最初の git commit から22時間、クラウドと戦った。 第9話、9時から22時まで、20回 push した。 第10話、AIが嘘をつかないようにコードを書いた。 第11話、現場21年の言葉をコードに翻訳した。 第12話、18日間で4つのプロダクトを立ち上げた。 第14話、フォームから LINE まで初めて自動で流れた。

13の節目を並べると、ひとつの法則が見えてくる。

ぜんぶ、「次のステップに進むために、目の前のひとつだけをやった日」だった。

「44歳から個人開発を始める」という大きな目標は、一度も自分の中になかった。

「動画やスライドが作れたら面白い」が、最初。 「ココナラとTikTokに何かを投げてみたい」が、次。 「AIにジャーナリングを手伝ってもらえないか」が、次。 「アプリ進めなきゃ」が、次。 「LINE Bot を作ってみよう」が、次。

それぞれの瞬間に、目の前のひとつを選んでいただけだった。

その小さい選択が、622日かけて、いまの自分を作っていた。

9ヶ月で変わった3つのこと

622日前の自分と、いまの自分で、明確に変わったことが3つある。

ひとつ目は、技術。

ノートPCのターミナルを開いて、git のコマンドを叩いて、コードを書いて、Cloud Run にデプロイして、Firestore のデータを確認して、エラーログを読んで、修正できるようになった。

これは、エンジニアからすると初心者レベルだろう。でも、44年間「コードは他人が書くもの」だった自分にとって、これは大きな変化だった。

ふたつ目は、メンタル。

「自分は作る人だ」と、心のどこかで思えるようになった。

44年間、自分は「会社の中で価値を生み出す人」だった。 いまは、「自分の名前で世の中に何かを置く人」になっていた。

これは、収入の話じゃない。実際、5プロダクトのうち4つは、まだ大した収益を出していない。

ただ、「自分は何かを作って、誰かに届けられる」という事実が、自分の中に積み上がっていた。

それは、44歳まで知らなかった種類の自信だった。

みっつ目は、現場との関係。

21年間、自分は「現場の人」だった。 いま、自分は「現場をコードに翻訳する人」になっていた。

第11話で書いた「クレンリネスはクレンリネスでいい」のように、現場で20年使ってきた言葉を、そのままコードに残せる。

これは、エンジニアが汎用システムを作るのとはぜんぜん違う種類の価値だった。

そして、その価値は、自分にしか作れないものだった。

5プロダクト並走の本当の意味

5つのプロダクトを並行で動かしていると言うと、よく「凄い」と言われる。

でも、本当のところを書くと、5つを並走できているのは、技術が凄いからじゃない。

5つとも、自分の周りの誰かのためのプロダクトだから、続いている、だけだった。

hidamari は、子どものために。 moyalog は、自分の過去の自分（と、同じように整理が必要な人）のために。 repimemo は、夜の店舗で働く人のために。 VAC は、自分の本業の現場のために。 okilockle は、自分の店舗のスタッフのために。

「誰のために作っているか」が、明確だった。

それぞれの「誰か」を思い浮かべながらコードを書く時間は、本業のシフトを作る時間と、本質的には変わらなかった。

「現場の誰かが、明日少し楽になる」を考えている時間。

これが、5プロダクトを並走させている、本当の動力だった。

技術じゃない。動機の解像度の高さだった。

まだ書いていないこと

連載14話を書いてきたが、まだ書いていないことがいくつもある。

例えば、5プロダクトのうち、まだ1人もユーザーがいないプロダクトの話。 例えば、自分が技術的に未熟で、何度もコードを書き直している話。 例えば、本業の年末繁忙期に、コードを2ヶ月放置した話。 例えば、いまも続いている「やるべきこと」と「やりたいこと」の揺れの話。

連載は「触り始めて9ヶ月の記録」だったが、「9ヶ月で全部解決した」わけじゃなかった。

むしろ、9ヶ月でいちばん分かったのは、「個人開発は終わりがない」ということだった。

プロダクトを作ったら、それを使ってもらう仕組みを作る必要があって、使ってもらえたら、改善する必要があって、改善したら、その改善が誰のためか確認する必要がある。

その輪は、たぶん、ずっと回り続ける。

622日前の自分が「生成AIを知った」だけだったように、622日後のいまの自分も、たぶん「個人開発の次のステップを知った」だけだった。

その次のステップが何かは、まだ見えていない。

でも、見えていないことを、見えていないまま、毎週日曜にこの連載で書き続けてきたのが、自分にとっての622日の集大成だった。

もし、いまこれから始めるなら（最終回版）

ここからは、いまの自分が、当時の自分と、これを読んでいるあなたに、まとめて伝えたいことを書く。

連載で書いてきた13の節目を、13行に圧縮するなら、こうなる。

  1. 課題が先、道具は後（第1話）
  2. コードを書く前に、何かを「出す」を体験する（第2話）
  3. AIを道具ではなく相棒として扱う（第3話）
  4. 感情と技術を分けない（第4話）
  5. 転職と開発を対立させない（第5話）
  6. 最初に動かすのは echo bot でいい（第6話）
  7. 動くものを作ってから道具を揃える（第7話）
  8. 自動デプロイから入らない（第8話）
  9. 月に1回でいいから20回 push の日を作る（第9話）
  10. 他人に迷惑をかけないコードを書く（第10話）
  11. 自分の現場の言葉をそのままコードに残す（第11話）
  12. 1個目の完成度より2個目以降の立ち上げ速度（第12話）
  13. 手作業が破綻する前に、フォームから LINE まで自動で繋ぐ（第14話）

13行に圧縮しても、たぶん、伝わらない。

伝わるとしたら、これを読んでいるあなたが、今夜のうちに、何か一つだけ「やる」と決めて、明日の朝までにそれを実行することだけだ。

ノートに「これからやりたいこと」を3つ書く。 ChatGPTに自分の話を聞いてもらう。 ココナラのプロフィール画面を開いてみる。 LINE Developers のサイトを開いてみる。

何でもいい。

「動く」を一度自分の手でやる。

それさえやれば、622日後のあなたが、いまのこの自分のように、5つの何かを並走させているかもしれない。

中身は、自分のプロダクトでも、自分の店舗でも、自分の本でも、自分の動画でも、自分の事業でも、何でもいい。

「自分は作る人だ」と思える1日があれば、その後の生活の解像度が変わる。

それを44歳の台風の夜に、自分は知らなかった。

622日かかって、いまようやく、知っている。

これを読んでくれてありがとう。

連載「触り始めて9ヶ月の記録」は、これで完結する。

でも、自分の触り始めは、たぶん、これからもずっと続く。

あなたの触り始めも、今夜から始まる、と思う。
