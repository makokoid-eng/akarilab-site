Privacy Policy

最終更新日：2026年4月23日

AkariLab（以下「当方」といいます）は、学習支援サービス「ひだまり」（以下「本サービス」といいます）における個人情報の取り扱いについて、以下のとおり定めます。

第1条　基本方針

当方は、利用者のプライバシーを尊重し、個人情報の保護に関する法律およびその他の関連法令・ガイドラインを遵守します。

特に本サービスは未成年者（小学生・中学生）を含む対象者に提供されるため、保護者の同意を前提として、必要最小限のデータのみを扱うことを基本方針とします。

第2条　取得する情報

2.1　LINEから自動的に取得する情報

  • LINE User ID
  • LINE表示名（プロフィール名）
  • プロフィール画像のURL
  • LINE上でのメッセージ送信内容

2.2　利用者から入力される情報

  • 学年
  • 使用教科書
  • 学習中の回答・質問内容
  • 問題への誤判定報告（テキスト・画像）

2.3　サービス利用により生成される情報

  • 学習進捗（正解数、クリア単元等）
  • 連続学習日数
  • 学習履歴
  • セッション開始・終了時刻

2.4　有料プラン契約時に決済代行業者（Stripe Inc.）を通じて扱われる情報

  • 氏名
  • メールアドレス
  • 決済に必要な情報
決済情報（クレジットカード番号等）は、Stripe Inc.が直接取得・管理します。当方はこれらの情報を保持しません。

第3条　利用目的

取得した情報は、以下の目的で利用します。

  1. 本サービスの提供および運営
  2. 学習支援の個別最適化（対話の生成・難易度調整等）
  3. 保護者への学習レポート提供
  4. 有料プランの契約・決済処理
  5. 利用者からの問い合わせ・サポート対応
  6. サービスの改善（利用者からの明示的フィードバックに基づく範囲に限る）
  7. 不正利用・規約違反の検知および対応
  8. 法令に基づく対応

第4条　第三者への提供

当方は、以下の場合を除き、取得した情報を第三者に提供しません。

4.1　AI事業者への送信

本サービスは、AI対話機能の実現のためOpenAI社の大規模言語モデル（GPTシリーズ）を利用しています。そのため、以下の情報がOpenAI社のAPIに送信されます。

  • 利用者の会話内容（問題への回答、質問等）
  • 学年・教科書情報（出題レベル判定のため）
  • 学習履歴（対話の文脈維持のため）
2026年4月時点のOpenAI社の利用規約に基づき、APIを通じて送信されたデータはOpenAI社のモデル学習には使用されません。

4.2　決済代行業者への提供

有料プラン契約時、Stripe Inc.に対して氏名・メールアドレス・決済情報を提供します。Stripe Inc.のプライバシーポリシーが別途適用されます。

4.3　ホスティング・インフラ事業者

当方は、以下のクラウドサービスを利用してデータを保管・処理しています。

  • Google Cloud Platform（データ保管、アプリケーション実行）
  • LINE Corporation（メッセージング基盤）

これらの事業者は、当方の管理下で当方の指示に従ってのみ情報を取り扱います。

4.4　法令に基づく開示

法令に基づき開示が求められる場合は、必要な範囲で開示することがあります。

第5条　誤判定報告機能におけるデータ取り扱い

本サービスには、利用者がAIの判定に疑問を感じた際、報告する機能があります。この機能を通じて送信されたデータは以下のように扱います。

  1. 報告内容（問題文、回答内容、画像等）は、当方のサービス改善目的でのみ利用します。
  2. 報告データの分析完了後、添付画像は速やかに削除します（目安：報告から30日以内）。
  3. 報告された情報の分析には、AI技術（OpenAI GPT-4o Vision等）を利用することがあります。
  4. 利用者は、この機能で送信した情報の削除を求めることができます。

第6条　データの保管期間

  1. 利用者がサービス利用中の期間、必要な情報を保管します。
  2. 退会時は、当該利用者の個人情報・学習データ・会話履歴を、原則として速やかに削除します。
  3. ただし、以下の情報については退会後も合理的な期間保存する場合があります。
  • 法令により保管義務がある情報（決済記録・取引履歴等、該当法令に定める期間）
  • 不正利用の検知・対応、および紛争対応に必要な最小限の情報
  • バックアップ上のデータ（通常のバックアップローテーション期間中に順次消去されます）
  1. 誤判定報告用の画像は、分析完了後30日以内に削除します。

第7条　未成年者の情報保護

  1. 本サービスは未成年者の利用を想定しています。
  2. 有料プランの契約および決済は、保護者（成人）のみが行えます。
  3. 未成年者の会話内容・学習履歴は、保護者が連携機能により閲覧できる場合があります（ただし保護者が見るべきでない内容は当方が判断し制限します）。
  4. 未成年者本人からの削除要求があった場合、保護者に連絡のうえ速やかに対応します。

第8条　クッキー・類似技術

本サービスはLINE上で提供されるため、ウェブサイトにおけるクッキーの利用は最小限に留めます。将来的にWebサービスを提供する場合は、別途クッキーポリシーを定めます。

第9条　利用者の権利

利用者は、自己の個人情報について以下を請求できます。

  1. 開示請求
  2. 訂正・追加・削除請求
  3. 利用停止・消去請求
  4. 第三者提供の停止請求

請求は、本ポリシー末尾の連絡先にご連絡ください。本人確認のうえ、合理的な期間内に対応します。

第10条　安全管理措置

当方は、取得した個人情報の漏洩・紛失・改ざん等を防止するため、以下の措置を講じます。

  1. 通信の暗号化（HTTPS、TLS等）
  2. アクセス権限の最小化
  3. データ保管サーバーのアクセス制限
  4. 定期的なバックアップ
  5. 従業員・委託先に対する個人情報保護の指導

第11条　ポリシーの変更

  1. 当方は、必要に応じて本ポリシーを変更することがあります。
  2. 重要な変更については、利用者に通知します。
  3. 変更後のポリシーは、本サービス内またはウェブサイトでの公表時点から効力を生じます。
